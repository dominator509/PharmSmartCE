# EP-003 — Data & Persistence

**Phase:** P2

## 1. Purpose / Big Picture
Translate `SPEC-002` into SQLAlchemy models, the initial Alembic migration, and repository classes. Persist FAISS indices per course. Integration tests use `testcontainers-python` for Postgres.

## 2. Scope
- SQLAlchemy ORM models for every table in SPEC-002
- Initial Alembic migration (idempotent against an empty DB)
- Repository classes per aggregate root
- FAISS persistence layer (per-course index file + metadata JSONL)
- Integration tests including the citation NOT NULL test

## 3. Non-goals

- Auth implementation (EP-006)
- Worker queue (deferred to EP-004/EP-008)
