# PharmSmartCE Blueprint Pack — Pack 2 of 2

This zip contains the **implementation pack** and overlays on the same
`PharmSmartCE/` directory created by Pack 1.

## Contents
- `.agent/execplans/` — 11 ordered ExecPlans (EP-000 through EP-010)
- `.agent/checklists/` — 9 operational checklists

## No file overlap with Pack 1
Unzip Pack 1 first, then unzip Pack 2 over the same directory. No file in
this zip exists in Pack 1.

## How to start
1. Unzip Pack 1 (if not already).
2. Unzip Pack 2 over the same directory.
3. Read `AGENTS.md`, then `.agent/execplans/EP-000-repository-discovery.md`.
4. Follow the ExecPlan to completion; do not implement from `ROADMAP.md`.
