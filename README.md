# PharmSmartCE

The world's first cloud-based SaaS Smart AI-powered Pharmacist CE Generator
with dynamic, per-user test questions grounded in uploaded CE source material
via a self-hosted CPU-only LLM.

**Start here:**

1. Read `PROJECT_BRIEF.md` to understand the product.
2. Read `AGENTS.md` if you are a coding agent (human or LLM).
3. Read `ROADMAP.md` for the strategic phase plan (do not implement from it).
4. Pick the active ExecPlan from `.agent/execplans/` and follow it.
5. Use only commands from `COMMANDS.md`.

**Do not implement from `ROADMAP.md` directly.** Implementation only happens
through an active ExecPlan.
